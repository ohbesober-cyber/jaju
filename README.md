# 자주 쓰는 말 (PWA)

자주 쓰는 문구를 저장해 두고 누르면 바로 복사하는 설치형 웹 앱입니다.

## 올리는 방법
PWA는 `https://` 주소에서만 설치됩니다. 이 폴더의 파일을 전부 같은 위치에 올려 주세요.

- GitHub Pages: 저장소에 파일을 올리고 Settings > Pages에서 배포
- Netlify, Cloudflare Pages: 폴더를 그대로 올리기

## 설치
- 안드로이드(크롬, 삼성 인터넷): 주소로 접속한 뒤 메뉴에서 "홈 화면에 추가" 또는 "앱 설치"
- 아이폰(사파리): 공유 버튼 > "홈 화면에 추가"

## 파일
- `index.html` 앱 본체
- `manifest.webmanifest` 앱 이름, 아이콘, 색
- `sw.js` 오프라인 보관. 파일을 고쳐 다시 올릴 때 `CACHE` 버전 숫자를 올리기
- `icon-*.png` 아이콘

## 참고
- 문구는 설치한 기기의 브라우저 저장소에만 남습니다. 브라우저 데이터를 지우면 함께 지워집니다.
